# Cochise Linux User Group Website

Website for the **Cochise Linux User Group (CLUG)** — a volunteer non-profit in Sierra Vista and Cochise County, Arizona, offering free Linux help, workshops, and community.

**Live site:** https://cochiselinuxusergroup.org

## What's here

- Meeting times, locations, and upcoming events
- Free computer & parts inventory for members
- Supported Linux distributions and resources
- Meeting notes and blog posts
- Contact and mailing list info

## Updating the website

Content updates (inventory counts, event dates, meeting notes, and the like) don't require any programming. See **[EDITING.md](EDITING.md)** for the plain-English, step-by-step guide.
