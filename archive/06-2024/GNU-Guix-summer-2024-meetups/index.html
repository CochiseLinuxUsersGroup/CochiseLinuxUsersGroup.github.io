CLUG:

In case anyone’s interested, the link posted below is for registration for this summer’s Guix Patch Review meetup sessions. One of them already happened, but I think the video is linked, and two more are scheduled this month.

GNU Guix is interesting to experiment with. It does not employ systemd. I’m running it on one machine as the barebones system, and on two others I have it installed on top of other distros. It runs the pure free kernel and won’t support anything proprietary - it won’t even install if the installer finds a proprietary wifi or graphics card (you’d have to manually install with proper patch) hence the workaround of installing it as an embedded system, like, “on top of” an existing distribution.
