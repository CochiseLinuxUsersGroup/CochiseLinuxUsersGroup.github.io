Since this happened there have been many updates to regular packages, which in my estimation have never been a problem, however, I have not updated anything for fear of updating the kernel again.
Is there a terminal command to update everything except for the kernel? Or is there a way to designate which kernel version I want to continue using? I've read a bit about grub-customizer but don't know enough about it.

Re: kernel update

From Devi Garcia · Apr 13, 2022

linux and  linux-firmware 

should be the main two packages for the kernel... 

another option.. and possibly a much easier one.. considering you're using manjaro is go into the kernel manager and switch to the "LTS" kernel.. and you'll just always be using a older stable kernel similar to ubuntu/debian and all those distros.. but all your other packages will update as soon as they get updated as normal.. you just won't be on the mainline kernel anymore..
