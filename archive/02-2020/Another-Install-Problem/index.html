Another Install Problem

From Rex Bouwense · Feb 04, 2020

A friend at the Warrior Healing Center had brought his old HP
Compaq dc5800 sff desktop last week and asked me to install a Linux OS
on it (other than Ubuntu which he had on one of his other machines).
After trying to boot from both DVDs and flash drives with numerous Linux
OSs (Xubuntu, Lubuntu, Linux Mint, MX Linux) I kept on getting a kernel
panic. I was eventually able to install Trisquel 8.0. Yesterday he
brought the computer back and stated that he wanted to donate it. I put
a different hard drive in it with Ubuntu already installed but the same
result, kernel panic. After several hours of research I discovered a
solution. The BIOS would not allow a boot from any kernel newer than
4.4 so it had to updated. Once again David came to the rescue with a
solution that I would never have thought of. The computer originally
had Windows Vista on it but was refurbished with Win7. There was a BIOS
update but of course it was supposed to be installed in a Windows
environment which no longer existed. David said try to boot from
Hiren's Boot CD. That would create a Win10 environment on the computer.
https://www.hirensbootcd.org/download/. I downloaded it and created a
boot DVD, located the BIOS update on the HP support website and
downloaded it as well. Long story shortened, the BIOS update was
successful and I was able to install Ubuntu 18.04.3 on the machine so it
now is ready for donation. Kudos once again to David, the Group's master
of the seemingly impossible computer tasks. I have retained the Hiren's
Boot CD should this problem raise it's head once again.

Rex Bouwense
