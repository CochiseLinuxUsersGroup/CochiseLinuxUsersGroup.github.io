FW: Tails and usb sticks

From Eugene Zastera · Feb 05, 2020

 

Remember the presentation on Tails?  I got one of the usb sticks and tried to clone it with CloneZilla.  It didn’t work.  Gave me messages that to boot the stick you need to edit etc/fstab and the grub loader.

 

If you follow the instructions on the website you can download an image file (.img) and a utility called Etcher.  Etcher will burn the .img file to the usb stick and it works flawlessly.

 

Just thought inquiring minds would want to know.

 

Just FYI.

 

Gene
