Re: acer install

From Rex Bouwense · Feb 10, 2020

    I would recommend that you install one of the distributions that Devi recommended, either Lubuntu or Xubuntu and I would stay away from the interim releases (18.10, 1904 - which have already reached their End Of Life - and 19.10).  Long Term Support (LTS) releases are supported for 5 years for Ubuntu and for 3 years for any one of Ubuntu "flavors" such as Lubuntu or Xubuntu.  The Interim releases are only supported for 9 months and while they tend to have the cutting edge software they are not as stable as the LTS releases.  Now, here is the rub.  Lubuntu 18.04 was released with Lightweight X-11 Desktop Environment (lxde).  All of the interim releases, including the latest 19.10, have used LXQT desktop environment.  Why does that matter?  There are different default applications and you will have to get used to them when installing the new LTS release (20.04).  No big problem but something that you should be aware of.  If you choose Lubuntu, 19.10 might be a release to start with to get used to everything and then upgrade or do a fresh install of 20.04 when it comes out in April of this year.
    We have installed both Lubuntu and Xubuntu on very small hard drives.  The smallest was 9.1 GB and there was plenty of room to update, create documents, and save photos and music.  Also something else that is relevant, a Linux distribution does not grow when there are updates as a Microsoft Windows does.  If you start with an installation that takes up roughly 5-8 Gbs of space on your hard drive, it is very likely that two years hence that same OS will still be basically the same size.  When it updates it replaces the old code with new code one line at a time.  None of the old code is saved (with the exception of kernels which have to be deleted manually - but a kernel is is only 68 Mbs and it is the guy that starts everything and tells everything else what to do.
    Devi also mentioned Bodhi Linux and Linux Lite OS.  If you are not satisfied with either Lubuntu or Xubuntu, they are excellent choices.  One additional operating system that he did not mention is Trisquel, https://trisquel.info/.  It is composed of entirely free and open source software. 

Rex
