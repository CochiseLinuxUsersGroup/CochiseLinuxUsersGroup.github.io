From Rex Bouwense · Jun 04, 2019

Read the article.  It only talks about the new beta release of LibreOffice.  Previous releases are still being supported.  Of course you will not have the new bleeding edge but they will still be quite functional and will be supported.  There are still many OS's that are supporting 32 bit computers and that will continue for a little while anyway.  You can even still download Ubuntu minimal in 32 bit.  Remember there are over 350 Linux OS out there.
