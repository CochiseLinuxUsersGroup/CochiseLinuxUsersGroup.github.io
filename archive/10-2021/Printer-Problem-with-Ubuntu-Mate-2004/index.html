Printer Problem with Ubuntu Mate 20.04

From Rex Bouwense · Oct 06, 2021

David,
I don't know what to tell you.  HP printers are the most Linux friendly printers around.  I have used them for years and in many cases you don't even have to install HPLIP.  They are recognized and print without doing anything.  I have never used the Mate desktop environment and my research does not indicate a problem with recognizing HP printers.  You can ask on the Mate forums https://ubuntu-mate.community/ or the Ubuntu forums https://ubuntuforums.org/.  perhaps there is someone there who can provide you with additional information.
Rex Bouwense

From Devi Garcia · Oct 06, 2021

before doing anything make sure that you’re repositories are up-to-date.

  1. 
sudo apt update & upgrade 

I’ve done that installing through installing HPLIP, you can get it straight from apt repositories like below:

  1. 
sudo apt install hplip hplip-data hplip-doc hpijs-ppds hplip-gui hplip-dbg printer-driver-hpcups printer-driver-hpijs printer-driver-pxljr 

or download the intended file from origin website for you’re specific OS.

I had some problems to run it, so installed some dependencies and it fixed.

  1. 
sudo apt install   python3-pyqt4 gtk2-engines-pixbuf python3-dbus.mainloop.qt 

then it warned me about the plugin is not installed so installed it this way.

  1. 
sudo hp-plugin -i -g 

then it was working for me.
