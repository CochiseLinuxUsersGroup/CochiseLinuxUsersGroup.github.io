[link] Kobol Helios64 open source NAS coming in March (network attached storage)

From Devi Garcia · Jan 02, 2020

Network Attached Storage (NAS) devices like those offered by Synology and QNAP are basically specialized computers that are designed to let you do things like back up your data or set up a home server. But for the most part they run proprietary software.

But Kobo’s upcoming Helios64 is designed to be a more open alternative. It’s an open hardware project that runs open source software.
