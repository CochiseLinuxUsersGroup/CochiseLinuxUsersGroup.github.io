Kernel Updates

From Rex Bouwense · Jan 28, 2020

A CLUG member emailed me with a problem he thought was caused by a new
kernel that he had downloaded and installed and he wanted to know how to
roll back the installation. Occasionally, when a new kernel is
released, downloaded, and installed, it breaks something. This is rare
because each distribution team checks the kernel before releasing it to
their repositories, however it does happen. Some time ago when I
upgraded the kernel on my Lubuntu 18.04 system, my trackpad stopped
functioning. I did not notice it until some time later when I used the
computer outside of my home because I use a wireless mouse there. I had
installed Lubuntu with kernel 4.15. Update 4.15.0-72 broke the
trackpad. I had three choices (according to the experts on the
forums). #1. Re-install Lubuntu 18.04.3 with the newer base kernel -
some variation of the 5.XX kernel. #2. Install a newer kernel. #3.
Roll back to the previous kernel (which was 4.15.0-70) where the
trackpad functioned normally and wait for a new version of that kernel
to be released. Option #1 is obviously overkill. I choose to roll back
the kernel. That is one of the reasons that Linux users keep two
functional kernels on the system. If something goes wrong with the
primary you always have a backup that you can choose to boot from. Then
you have a functioning system. The backup kernel should obviously be
one that you have used and already know works well on your system. Long
story shortened, the next version release once again had my trackpad
functioning as normal.

Rex bouwense
