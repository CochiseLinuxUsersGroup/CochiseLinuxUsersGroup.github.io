(link) GitHub - soofstad/boot-to-windows: A wrapper for &#x27;grub-reboot&#x27;

From Devi Garcia · Mar 29, 2019

A very simple program that adds a desktop entry for a short script that uses 'grub-reboot' to reboot once into Windows on you dual boot setup. You can then setup GRUB to default into Linux and skip the GRUB menu altogether, making for a faster boot time, and removes the need to select a boot option from the GRUB menu, which is sometimes a bit of a hassle.


https://github.com/soofstad/boot-to-windows
