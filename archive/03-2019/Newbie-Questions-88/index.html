From Rex Bouwense · Mar 25, 2019

    It was a pleasure having someone from the North part of the county present.  We are a county organization and currently have members/attendees from Saint David, Bisbee, Benson, Hereford, Dragoon, Sunsites, and Sierra Vista as well as a few from outside of the county.
    If you are booting both Ubuntu and Microsoft Windows without problems, continue with that set up until you are very comfortable with Linux.  Continuing to do your work in Windows while learning the new OS and the Free and Open Software equivalents.  You will find that the learning curve is much shorter than it was when learning Microsoft Windows.  People that install a Linux OS in a dual boot mode usually tend to use Windows less and less until they rarely boot into at all.
    Many Windows applications will run in a Linux operating system with a program called WINE.  You would have to check https://appdb.winehq.org/ for compatibility.  Not all Widows programs will work.  There are several members in the LUG that use Wine for some programs and I am sure that you will hear from them in time.

Rex Bouwense
