You could use an iso you acquired and install it via VM it doesn't really "mount" it it full installs it on virtual media.. due note current windows requires all updates to do be done first and requires a Microsoft account to use it... 

Alternatives are Windows PE which is a bootable media of windows for repairing broken machines but should work well enough for any windows based tasks..

Doing it in Linux also Winboat or other Windows docker versions which skips the need for virtual machine software and just access it via a webserver locally hosted..
