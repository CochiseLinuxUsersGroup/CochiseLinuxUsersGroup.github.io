Another Noob Tests The Water

From Lee Ilse · Mar 15, 2020

Downloaded Lubuntu 18.04 yesterday and made a bootable thumb drive using Rufus this afternoon. This evening I was able to boot Lubuntu from the stick and test drive the OS on the Mini-9. It did take a couple minutes to load from the stick - I’m not sure if this was because of the ancient CPU or the rather slow USB 2.0 port. But it looks good and ran the word processor and Firefox OK - so tomorrow I will load it on the SSD drive and that should boot quite a bit faster. Thanks again guys!

Best Regards,
