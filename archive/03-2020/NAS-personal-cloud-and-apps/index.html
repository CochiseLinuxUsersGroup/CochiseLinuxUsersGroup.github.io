NAS / personal cloud and apps

From Laco K · Mar 22, 2020

Fellow Linuxers,

I've been thinking about setting up my NAS / personal cloud for multiple obvious reasons. One issue I haven't solved / found an answer to yet is this:
I use in my business and personal life various desktop apps, eg Quickbooks. And while I know there is an online version of this app, my CPA doesn't consider the online version to be equivalent to the desktop version. And no, I'm not finding a new CPA over this issue.
So my grand idea would be to install the desktop app in the cloud and be able to access and use the app remotely from any comp, esp one that's not running the app software natively. Is this doable? There are both windows or a mac version of Quickbooks. I know the cloud setups use NAS or a variety of Linux. I refuse to use Windows any longer, esp since W7 is not supported. I know i can remotely log into a comp (not NAS / not cloud) that has the app installed on it, which is what I've been doing lately. But it's not the same as what I was thinking about accomplishing with the NAS / personal cloud.

any insight would be appreciated,

stay safe,

L
(Solus and Manjaro)
