I used to have a similar netbook. Mine was an ASUS with the Atom
processor with 1 GB of RAM. I did run Lubuntu on it as well as Bodhi
Linux. Neither is very resource intensive. Lubuntu 18.04 and Bodhi 5.0
still have 32 bit versions. Another distro that will probably run on it
is Trisquel 8.0 mini. It also still has a 32 bit version. You could
try all three and see which you prefer.
