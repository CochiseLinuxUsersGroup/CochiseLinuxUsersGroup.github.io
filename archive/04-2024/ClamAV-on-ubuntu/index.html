In school I used Clam AV regularly on Ubuntu. Back then it wasn't an always on, preventative AV. You have to update it and run it manually daily. If you tried to run another AV, there would likely be a conflict because they check the same places and will alert on each other's virus signature files. All you can do is trial and error testing. Just add one thing and verify functionality 1 product at a time. And report back please, let us know what you learn.

Good luck,

Annette Carter.
