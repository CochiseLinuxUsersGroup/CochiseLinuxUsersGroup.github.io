Ubuntu 22.04.3 release

From Rex Bouwense · Aug 11, 2023

For those of you that are using Ubuntu or one of the official flavors,
22.04.3 has been released and can be downloaded at:
https://ubuntu.com/download/desktop#download. Links to torrents and
Ubuntu flavors can also be found on that page. You do not have to
re-install. If you have been religiously updating your computer, you
already have 22.04.3 installed. I urge you to download the OS that you
are using on your computer and create a bootable flash drive should it
be necessary to re-install if that situation should arise.

Rex
