Re: Linux distros update Firefox while Firefox is running

From Rex Bouwense · Jul 07, 2022

Using 20.04 you have the deb version.  It sounds like you have your Software and Updates set to download and install for all updates.  Merely select a different option like display immediately.  Once it displays that there is an update to Firefox, select it to get rid of the check mark or select remind me later so you can continue to use the old Firefox.  Once you are finished using Firefox, then update it.  I know of no way to continue using the old Firefox once it has been updated because it no longer exists on your computer.  It has been replaced by the updated version.  That is something that you have to live with.
Rex
