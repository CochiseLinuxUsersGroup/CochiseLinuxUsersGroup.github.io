Upgrades are patches to the programs that you have installed. Many are
security updates which you need to protect your system from various evil
doers out there in Internet-land. They are issued to improve your
system but occasionally they do break something else. So the general
answer to your question is yes install all of the updates. They are not
bloating your system, only correcting it. Unlike Microsoft updates,
these updates are mainly very small corrections so no large increase in
your
OS size occurs.
Rex
