From Devi Garcia · Jul 24, 2019

https://www.youtube.com/watch?v=3i7fXe1bWyU

Couple Corrections from the Video:
1. Official Repos for gnome extensions are
https://extensions.gnome.org/ and themes are https://gnome-look.org
2. This is technically Malware targeting GNOME not Linux per se... so
BSD OS's would also be vulnerable to this type of attack.
3. It requires the user to make a series of extremely poor decisions
to infect the host. Downloading from an untrusted source, marking it
executable, and running said executable as superuser. Check for
Infection: To check if your Linux system is infected with the
EvilGnome spyware, you can look for the "gnome-shell-ext" executable
in the "~/.cache/gnome-software/gnome-shell-extensions" directory.
