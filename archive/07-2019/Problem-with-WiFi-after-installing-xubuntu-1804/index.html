From Devi Garcia · Jul 13, 2019

https://help.ubuntu.com/community/WifiDocs/Scan_for_Wireless_Network

If that doesn’t show any devices your WiFi card could very well have been removed from the kernel modules as it’s an older machine and you’d then have to figure out what WiFi card you have in the machine and install the modules etc yourself.. or go to an older Ubuntu release where it was known to work...
