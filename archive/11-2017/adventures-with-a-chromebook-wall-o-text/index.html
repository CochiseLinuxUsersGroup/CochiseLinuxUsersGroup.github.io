adventures with a chromebook [wall o text]

From Devi Garcia · Nov 27, 2017

so since i've never used a chromebook but always wanted too i took the one Rex got from Bill and played with it.. enabling dev mode.. which increased the usefulness of it by adding the playstore and allowing me to install android applications.. but this wasn't enough.. so i played with crouton which Rex had working with Lubuntu.. i got one chroot working with xenial and budgie.. but i ended up having issues with it installing nothing but the actual desktop and nothing else.. and once i installed the software center i kept having policy errors allowing me to install nothing.. but i did get this working with the chrome extension to easily switch from chromeos to that with a click from the browser... i attempted again with lxde and artful but that went fullscreen immediately and i couldn't figure out how to minimize it without rebooting the pc....

me being me though i wanted to get into the bios modifications that are out there for actual linux installs that replaces chromeos.. this required me to open the whole laptop and pop off the keyboard and unscrew a screw on the motherboard that write protects the emmc.. so i initially tried "john lewis's" RW_LEGACY mod.. which allows a legacy bios to boot and i got Solus3 budgie fully installed/updated and working.. with no issues other than no audio device.. after a few hours of trying various fixes/replacing files to get the audio working.. i tried "MrChromeBox" RW_LEGACY mod which is suppose to be newer/better.. and still no audio devices and i even tried the headphone port to make sure that didn't work either... i did notice tho this other guys had full rom support for the chromebook i had... which completely erases and rewrites the bios to a modded one with full UEFI support to even allow windows installs on the chromebook.. so i tried this one.. and it worked without bricking the laptop.. YAY and i tried my solus3 usb wouldn't boot but to the bios settings.. so i made a antergos/arch usb bootable and got that installed after some issues of arch not wanting to see the internal emmc drives.. after i got that installed.. my bios never booted past the first screen regardless of the installed OS and when i looked into the bios settings all were set right...

so now that i was in the land of no return and i didn't backup my stock bios.. i had to try and restore it.. so i booted antergos to run the script to return the bios back.. to only find out it didn't have the tool in the live cd i needed.. so now onto my third distro.. i got the 17.10 budgie  ubuntu live CD and i booted that and ran the firmware utility on that to restore my bios back to googles chromeos bios.. again more warning screens of bricking the device.. but luckily again it flashed just fine.. then i went on to get a portable version of chrome running on my desktop to make a restore media for chrome os... and in the end.. the chromebook is back on ChromeOS Dev Channel and fully stock.. with Developer Mode enabled and the bitmaps removed so the post screen doesn't blind me with that bright screen..

in the end.. the chromebook can run a full linux distro in RW_:LEGACY if the user is willing to forgo having any audio on the laptop.. and its not the fastest experience by any means.. but applications do load within a few seconds not just instantly.. i figured this may be useful info for anyone else may be interested in buying a chromebook to convert to a actual PC or just wants to use crouton/chrx and dualboot the two OSs
