On Line Meetings

From Rex Bouwense · Apr 01, 2020

I have just received permission from the Ubuntu-Arizona Local Community
Team (AZLOCO) to use their Big Blue Button Server for on line CLUG
meetings. This has been in the works for a long time. It has audio and
video capabilities as well as public chat and is relatively easy to
join. No additional software must be installed to use it. So now I can
ask the mailing list who would be interested in attending on line
gatherings. Please respond so we can set up date and time for an
initial meeting. I do not want to waste AZLOCO's time and resources if
there is no interest.
Rex Bouwense
