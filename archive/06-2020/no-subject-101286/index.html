Just upgraded to 20.04. Had a nightmare to get firefox to play online videos.
Took me days! to find the solution. Can't believe conical would send out a distro with faulty firefox. Anyway, in case you have the same problem here what fixed it for me:  
If those streaming services use DRM, you must enable DRM in Firefox's settings: Preferences -> General -> Play DRM-controlled content You might also have to install package libavcodec-extra to get the codecs:
sudo apt install libavcodec-extra
