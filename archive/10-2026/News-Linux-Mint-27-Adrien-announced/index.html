[News] Linux Mint 27 "Adrien" announced

From Devi Garcia · Oct 26, 2026

Linux Mint 27 "Adrien" is coming for Christmas 2026, and it changes
how Mint versions work:

- One release a year from now on, numbered for the upcoming year - no
more point releases. Mint 28 follows next year.
- The old girls'-name codenames (Ada through Zena, since 2006) are
done - boys' names now, starting with Adrien.
- Linux Mint 23 never existed: "23" and "Alfa" were just placeholders
while the team settled the new release strategy.
- The longer cycle leaves room for new projects: a Clocks alarm app
(via the Clockenstein calendar project) is in, and Superlight, Unfold,
and Velocitty are getting finishing touches.
- Based on Ubuntu 26.04 LTS, with Wayland support and a kernel removal
feature already done.

Full article: https://itsfoss.com/news/linux-mint-27-announced/

Re: [News] Linux Mint 27 "Adrien" announced

From Devi Garcia · Oct 26, 2026

Yes, you will be able to upgrade directly from your current version to Linux Mint 27.  The next major release is numbered 27 (codenamed "Adrien") because the project switched to a year-based numbering scheme starting in 2026, effectively skipping versions 23 through 26.

-Upgrade Path: Users on the current LTS release, Linux Mint 22.3 "Zena", can upgrade to Mint 27 using the standard mintupgrade tool or via the Update Manager once the release is available.
-No Intermediate Versions: Because point releases (like 22.1 or 22.2) are discontinued for the new yearly cycle, there are no intermediate major versions to upgrade to first; the jump goes directly from the last 22.x release to 27.
-Future Upgrades: Moving forward, upgrades will follow a similar pattern where you upgrade from one year-numbered release to the next (e.g., 27 to 28) once per year, rather than dealing with frequent six-month cadences.
