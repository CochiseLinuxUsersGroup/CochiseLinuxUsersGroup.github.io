From Devi Garcia · Oct 08, 2026

PhotoCraft is a new open-source image editor from the ArtCraft team: a
clean-room reimplementation of Adobe Photoshop written from scratch in
pure Rust. Same menus, shortcuts, panels and tools, so Photoshop
muscle memory carries straight over.

What it does: layers, masks, 16 adjustment layers, layer styles, type,
vectors and brushes on a native GPU canvas (Metal/Vulkan/DX12/WebGPU —
no Electron). It opens and saves real layered PSD/PSB files. Every
action is also a command, so it can be driven from the CLI, a JSON
channel, or an MCP server by AI agents. Native builds for Linux,
macOS, Windows, FreeBSD and the web.

What it replaces: Adobe Photoshop and its subscription. For Linux
users, a Photoshop-familiar alternative to GIMP.

Honest caveat: it's early alpha. The project's own README says it's
not yet a daily-driver Photoshop replacement — no generative/AI
features yet, ~20 tools still missing, no plugin support.

It's one of seven apps in the Crafting Apps suite covering Photoshop,
Illustrator, Premiere, Lightroom, Acrobat, After Effects and InDesign
equivalents.

https://getartcraft.com/apps/photocraft
https://github.com/storytold/photocraft
