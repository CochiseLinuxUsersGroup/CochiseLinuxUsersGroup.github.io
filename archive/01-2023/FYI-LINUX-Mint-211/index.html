FYI : LINUX Mint 21.1

From " · Jan 10, 2023

Greetings All,

Right around the New Year came a timely new release of LINUX Mint 21.1. I mention timely as Microsoft is ending support for MS Windows 7 & 8. Here is a possible alternative for those seeking a way forward while using existing hardware along with a comfortable similar menu driven desktop environment. This is a 64 bit operating system so a compatible computer is necessary. I will add that I have successfully run this on several systems such as one with a first generation i5 CPU (a now rare three digit version).

From the release notes:

This is Linux Mint 21.1, codename Vera.

Linux Mint 21.1 is a long term support release which will be supported until 2027. It comes with updated software and brings refinements and many new features to make your desktop experience more comfortable.

<Home - Linux Mint>
Home - Linux Mint

Linux Mint

Linux Mint is an elegant, easy to use, up to date and comfortable desktop operating system.

Some virtues not mentioned are those that I have explored and confirmed:

- The Linux Mint ISO file is roughly half the size of the current Ubuntu distribution ISO images. This may be a consideration if you have limited system resources.

- A basic level user will find minimal need to obtain additional software beyond that native to the distribution. Of course your mileage may vary depending on your personal needs. Most will find the browser and associated software helpful. The compatibility with Ubuntu repositories along with support from FlatHub greatly expands software support.

My personal experience using Linux Mint 21.1 has been positive and encouraging when using it for consuming on line mixed multi-media. My content creation tasks have been limited to word processing, image editing, and casual network security testing. I have been test driving it on several older computer systems greater than six years old. It has provided a stable usable desktop environment in each computer system.

I have mainly used and assessed the Linux Mint Cinnamon desktop environment and found it easy to use as it parallels the MS Win7, and XP menu focus. There are several other desktop environments available. You can simply select the appropriate ISO image for download.

I'm also happy to report successes when dealing with Linux Mint ISO images. I have been successful using them when burnt to optical media for both full installation and / or testing via live sessions. I have experienced similar success transferring the ISO image to USB pen drives and booting from solid state storage too.

Note this has not been the case for some other recent Ubuntu images which seem to prefer booting from solid state devices as there may some timing constraints for services started during boot up. This can be an issue when using slower optical transfer. I am still investigating those issues but at least there are successful alternative boot method(s(.

I have used it successfully with multiple displays where I have both duplicated the primary display and extended the desktop to a second display. Both configurations are accomplished easily. During my use of Linux Mint I have only experienced solid stable performance of it on both desktop and mobile (notebook / laptop) systems.

While it is based on an older version of Ubuntu, the fresh look with the native theme(s) are nice. My greatest appreciation is the ease of use that comes from that strong parallel to Microsoft operating system environments. You can easily navigate through the menus or simply direct entry search to find what you seek.

My assessment of Linux Mint 21.1 has only been for a few weeks as it was released just before the New Year. I'm happy to let others know it is a nice alternative that is available. and easy to use at the basic to intermediate Linux user levels. I've just not had the time to take it up several notches but based on this early experience it is promising.

Wishing each of you a wonderful new year! Be well, and Cheers!

We have been accepting computer donations (many of them older and some even 32 bit) cleaning them up and installing a Linux OS on them for many years.  Our go to distro used to be Lubuntu but they quit supporting 32 bit processors after 2018.  We now use Linux Mint Debian Edition, Anti X, and MX Linux for those computers.  We now recommend Ubuntu or Linxux Mint for the 64 bit processor computers.  If we can we also upgrade the RAM.  To date the Group has donated 89 computers to individuals and groups.

Rex Bouwense

G'day Rex, and et al.,

Bravo! Applaud your efforts in refurbishing computer systems.Yes, that was noteworthy when I reviewed the group's information. I have been aware of the group's existence and efforts for some time through posting at the SV U of A campus. Unfortunately my limited availability constrained participation. Even now I'm making time to share info to assist where I can. Hopefully, in the near future I may be able to participate at a greater level. At this time it is good to be able to confer with those engaged in using Linux for benevolent application.

Yes, if memory serves Ubuntu 18 (along with associated distributions) was the last 32 bit edition supported. It is late in the day so the search engine between the ears might be off a bit. It still has great utility as a reasonably robust desktop option. I mostly stopped mucking with it unless I've got a compelling reason. My only pressing concerns with using the older 32 bit distributions would be security related aspects. If you're just just using it as a internet kiosk then it is all good to go. If you're intending to process sensitive content then better to use something with a robust security posture.

Typically when investigating potential systems as refurbishing candidates, I use lightweight Linux distributions just to quickly assess things. It gives me a handy tool to confirm are all the components in the system functional or just to provide me vital information on all the active elements. Helpful with obtaining or configuring drivers and etc.

My most used tool is usually some version of Puppy Linux. Puppy has a range of options in both 32 and 64 bit distributions. These are very lightweight in nature and intended for "live" sessions. I fully appreciate the lightweight nature of Puppy in that it fully instantiates in system RAM. This allow you to disassociate the boot media (optical or usb storage). Very helpful in system recoveries. You're able to use the existing system peripherals without committing them in support of the live session.

The wide range of Puppy variants available also permit a user selecting something within a comfort zone for low resistance operations. Example desktop variants are based on lightweight versions of Slack, Ubuntu, and etc. There is additional language support too. Pick the comfortable one and go with it. Realize I emphasize "lightweight" as they boot fast and have most of the utilities to be useful. I mention utilities that are native to the distribution (graphical and command line). So you're not having to go on line to pull stuff down to use. Examples here are such as terminal communications, format and partition tools, system interrogation such a system inventory scan to include port assignments, and such.

Lightweight distributions are not the best choice to be used in a robust manor. They are really helpful if you just want to spin a system up to see what is working and what is not. Sure saves a great deal of time and effort.

Yes, over years of "goofing" on computers it used to be my aspiration to maximize RAM where I can. These days after demonstrating the massive system performance gains of transitioning to solid state drives (storage) my focus has shifted. I initially got the experience through using light weight fully live versions of Puppy Linux. Since the entire session is in a RAM drive the system's on board storage is not a constraint to performance. So using the older computer systems even with the 32 bit CPUs the performance was impressive when simply using the computer as an internet kiosk of sorts. Try it on a 64 bit machine and it is hard to go back to a spinning hard drive instantiation. Even with very minimal RAM capacity the results are interesting.

These days if the system has some workable level of RAM I just focus on testing the system using one of the SATA SSDs just to see what the system is really capable of doing. I am grateful the cost of SSDs has lowered along with elevated availability. It doesn't need to be big in capacity. Having fast storage is great cause you can see just how fast the older CPUs can rock the Casbah when there is little to no caching delay even at minimal RAM capacity.

Again just a reality check here. No you're not going to get an old dual core CPU to keep up with the new 12 gen Cores but it is amazing how restrained the old machines were due to the slow spinning hard drives moving data back and forth along the data bus.

Accolades to you and the others with success in getting folks computers. Bravo! Well Done! I hope to assist in a more meaningful way in the future when my personal schedule allows. Currently I'll assist with troubleshooting where I hope my experience will improve the situation.

Glad to join in on a constructive dialog. Wishing you and others a wonderful new year! Be well and cheers!

Linux Mint

Linux Mint is an elegant, easy to use, up to date and comfortable desktop operating system.

Some virtues not mentioned are those that I have explored and confirmed:

- The Linux Mint ISO file is roughly half the size of the current Ubuntu distribution ISO images. This may be a consideration if you have limited system resources.

- A basic level user will find minimal need to obtain additional software beyond that native to the distribution. Of course your mileage may vary depending on your personal needs. Most will find the browser and associated software helpful. The compatibility with Ubuntu repositories along with support from FlatHub greatly expands software support.

My personal experience using Linux Mint 21.1 has been positive and encouraging when using it for consuming on line mixed multi-media. My content creation tasks have been limited to word processing, image editing, and casual network security testing. I have been test driving it on several older computer systems greater than six years old. It has provided a stable usable desktop environment in each computer system.

I have mainly used and assessed the Linux Mint Cinnamon desktop environment and found it easy to use as it parallels the MS Win7, and XP menu focus. There are several other desktop environments available. You can simply select the appropriate ISO image for download.

I'm also happy to report successes when dealing with Linux Mint ISO images. I have been successful using them when burnt to optical media for both full installation and / or testing via live sessions. I have experienced similar success transferring the ISO image to USB pen drives and booting from solid state storage too.

Note this has not been the case for some other recent Ubuntu images which seem to prefer booting from solid state devices as there may some timing constraints for services started during boot up. This can be an issue when using slower optical transfer. I am still investigating those issues but at least there are successful alternative boot method(s(.

I have used it successfully with multiple displays where I have both duplicated the primary display and extended the desktop to a second display. Both configurations are accomplished easily. During my use of Linux Mint I have only experienced solid stable performance of it on both desktop and mobile (notebook / laptop) systems.

While it is based on an older version of Ubuntu, the fresh look with the native theme(s) are nice. My greatest appreciation is the ease of use that comes from that strong parallel to Microsoft operating system environments. You can easily navigate through the menus or simply direct entry search to find what you seek.

My assessment of Linux Mint 21.1 has only been for a few weeks as it was released just before the New Year. I'm happy to let others know it is a nice alternative that is available. and easy to use at the basic to intermediate Linux user levels. I've just not had the time to take it up several notches but based on this early experience it is promising.

Wishing each of you a wonderful new year! Be well, and Cheers!
