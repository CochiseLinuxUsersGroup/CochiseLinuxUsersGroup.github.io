FYI : LINUX Mint 21.1

From " · Jan 10, 2023

Greetings All,

Right around the New Year came a timely new release of LINUX Mint 21.1. I mention timely as Microsoft is ending support for MS Windows 7 & 8. Here is a possible alternative for those seeking a way forward while using existing hardware along with a comfortable similar menu driven desktop environment. This is a 64 bit operating system so a compatible computer is necessary. I will add that I have successfully run this on several systems such as one with a first generation i5 CPU (a now rare three digit version).

From the release notes:

This is Linux Mint 21.1, codename Vera.

Linux Mint 21.1 is a long term support release which will be supported until 2027. It comes with updated software and brings refinements and many new features to make your desktop experience more comfortable.

Linux Mint

Linux Mint is an elegant, easy to use, up to date and comfortable desktop operating system.

Some virtues not mentioned are those that I have explored and confirmed:

- The Linux Mint ISO file is roughly half the size of the current Ubuntu distribution ISO images. This may be a consideration if you have limited system resources.

- A basic level user will find minimal need to obtain additional software beyond that native to the distribution. Of course your mileage may vary depending on your personal needs. Most will find the browser and associated software helpful. The compatibility with Ubuntu repositories along with support from FlatHub greatly expands software support.

My personal experience using Linux Mint 21.1 has been positive and encouraging when using it for consuming on line mixed multi-media. My content creation tasks have been limited to word processing, image editing, and casual network security testing. I have been test driving it on several older computer systems greater than six years old. It has provided a stable usable desktop environment in each computer system.

I have mainly used and assessed the Linux Mint Cinnamon desktop environment and found it easy to use as it parallels the MS Win7, and XP menu focus. There are several other desktop environments available. You can simply select the appropriate ISO image for download.

I'm also happy to report successes when dealing with Linux Mint ISO images. I have been successful using them when burnt to optical media for both full installation and / or testing via live sessions. I have experienced similar success transferring the ISO image to USB pen drives and booting from solid state storage too.

Note this has not been the case for some other recent Ubuntu images which seem to prefer booting from solid state devices as there may some timing constraints for services started during boot up. This can be an issue when using slower optical transfer. I am still investigating those issues but at least there are successful alternative boot method(s(.

I have used it successfully with multiple displays where I have both duplicated the primary display and extended the desktop to a second display. Both configurations are accomplished easily. During my use of Linux Mint I have only experienced solid stable performance of it on both desktop and mobile (notebook / laptop) systems.

While it is based on an older version of Ubuntu, the fresh look with the native theme(s) are nice. My greatest appreciation is the ease of use that comes from that strong parallel to Microsoft operating system environments. You can easily navigate through the menus or simply direct entry search to find what you seek.

My assessment of Linux Mint 21.1 has only been for a few weeks as it was released just before the New Year. I'm happy to let others know it is a nice alternative that is available. and easy to use at the basic to intermediate Linux user levels. I've just not had the time to take it up several notches but based on this early experience it is promising.

Wishing each of you a wonderful new year! Be well, and Cheers!
