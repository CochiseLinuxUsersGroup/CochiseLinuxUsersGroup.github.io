I am not sure how I set up the update config on that computer.  You can check it by selecting Software and Updates from the main menu (the blue circle with the A inside of it).  Then select Updates.  You can configure it to your desires.  It will tell you when there are updates and you manually select install now or remind me later. 

You can check for updates yourself by selecting the grey circle with the A inside of it.  That will tell you if there any updates since the last check.  Or your can open a terminal and type sudo apt update.  That will also tell you if there are any updates.  To install them type sudo apt upgrade.
