Greetings George and et al.,

Just wanted to add information regarding your posting.

Using the compression tools to password protect file(s) is a helpful solution to privacy.

Another relatively easy thing to do is to review and properly assign file system permissions as the system administrator. Much of this is done by default when establishing a new user to the system. However as administrator it is to your benefit to assure things are as you want them to be when it comes to reading, writing, and executing permissions.

The built in graphical tools in the file manager can help with that administrative task.

OK, that being said if you find you need the next level of privacy read on. Otherwise have a good one.

Depending on your overall goals there are options for full disk encryption for furthering privacy goals. Obviously this is more involved for hardware and software.

On the software side of things full disk encryption is supported in Ubuntu and Linux Mint. Depending on your privacy goals and performance considerations this may be a choice for consideration.

To make full advantage of these encryption features you'll need hardware that supports these contemporary features such as a CPU with the appropriate TPM 2.0 (Trusted Platform Module) along with UEFI Secure Boot (Unified Extensible Firmware Interface, disk support) which involves create encrypted disk partitions.

Using full disk encryption is a significant system load and is better supported with the latest hardware. Such as using robust CPU with higher speed memory and storage (solid state drives).

I hope this helps with your situation. Happy New Year. Be well, Cheers!
