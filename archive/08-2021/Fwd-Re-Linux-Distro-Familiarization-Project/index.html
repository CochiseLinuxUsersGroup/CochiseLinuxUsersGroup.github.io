Fwd: Re: Linux Distro Familiarization Project

From J B · Aug 26, 2021

I have never successfully dual-booted a mac into linux. There’s some extra kajiggering that’s required beyond what Bootcamp can do for you. Parallels is a good hypervisor because it lets you boot into the guest virtual machine from the Mac desktop and integrate a lot of the features of the guest VM into the Mac desktop, like adding the guest applications to the host launch pad. If you want to go cheap, though, I think you can run Virtualbox (one of the hypervisors of choice for the Cochise College IT students) and install a linux VM on that. Won’t be integrated with the Mac desktop but it will run Linux on a Mac.
