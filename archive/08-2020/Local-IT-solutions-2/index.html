Re: Local IT solutions?

From Devi Garcia · Aug 17, 2020

Building your own server and using TrueNAS (https://www.ixsystems.com/truenas/) / FreeNAS (https://www.freenas.org/) are going to be your free OS options with others like OpenMediaVault, Xpenology and Ubuntu server, CentOS etc with Docker or “Jails” as freenas calls them..

Unraid does charge after a certain hard drive amount so that’s not a completely free solution... and if your looking for a prebuilt server basically Synology rackmount or any of their higher end models support docker and and can run synocommunity packages so you can between those two get any service you’d like running in a prebuilt box you just add drives in.. I personally run a 8 bay Synology with about 6-7 docker images running random servers for me with no issues..

As far as “professional” help.. you’d be stuck with our only PC shop.. and you’d be about $400 + parts + tax for just the build and OS install and they won’t manage or setup anything for you... they’d just built the server/tower and install your OS of choice...
