[Tool/Diag] Hiren&#x27;s Boot CD/USB

From Devi Garcia · Jul 26, 2020

Hiren’s BootCD PE (Preinstallation Environment) is a restored edition of Hiren’s BootCD based on Windows 10 PE x64. Since there are no official updates after November 2012, PE version is being developed by Hiren’s BootCD fans. It includes the least, best and updated free tools used in Hiren’s BootCD. It is being developed for the new age computers, it supports UEFI booting and requires minimum 2 GB RAM.

With the useful tools inside of the ISO, you can solve many problems related with your computer. It does not contain any pirated software, it includes only free and legal software.



https://www.hirensbootcd.org/


---

This was mentioned within a few conversations when came to hard drive testing or just any other hardware testing you may need to do.. and can't really use the host OS to do such activities.. or tools like Seatools/Seatools for DOS wont work.. This CD has multiple tools to test that hardware to let you know if it's good or bad.

Re: [Tool/Diag] Hiren&#x27;s Boot CD/USB

From Rex Bouwense · Aug 04, 2020

Dan,
It sounds like your boot loader is the problem.  Are you running Ubuntu or a derivative of it?  If so GRUB might be broken or overwritten.  When you start the computer, hold down shift.  You should see a list of installed OS.  If you do not then it is likely that is the case.  If you see the OS then GRUB is not the problem.  To repair the boot loader.  Restart your computer with the install disk inserted.  Make sure you are connected to the internet.  Open a terminal and enter:

sudo apt-add-repository ppa:yannubuntu/boot-repair
sudo apt update
sudo apt install -y boot-repair
boot-repair

This will install the boot-repair tool and run it after the final instruction. Wait for the system to be scanned, then select Recommended Repair.
This is part of my next presentation "What to do if Ubuntu will not boot" to be given on 22 August. 

Rex
