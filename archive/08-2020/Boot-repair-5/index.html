If I wasn't so rusty I'd offer more specific advice...  That being said, Linux is designed to be modular so worse case scenario you fubar'd grub.  I would suggest grabbing a liveCD / USB drive with the version you are using installed.  Reboot the system if it works, great.  If it doesn't boot up your live disk and use that to repair/reinstall grub.

Not sure if this is exactly what you need but it's a starting point.

https://help.ubuntu.com/community/Grub2/Installing#via_Partition_Files_Copy
