on-screen keyboard

From Eliter · Jan 30, 2021

So I have a 2-in-1 laptop that is running Ubuntu 20.04 (with the new desktop environment that is pre-installed Rex loves). The physical keyboard gets disabled when you flip it over past 180 degrees.
 I would like to have the on-screen keyboard come on ONLY when I flick my touch screen from bottom-up. However, the settings only allow for "enable" and "disable" of the on-screen keyboard. When I enable the on-screen keyboard, then it will open ANY time I open up a text dialogue, even if the physical keyboard is enabled and I didn't use the touchscreen, which is annoying.
 Basically, when I want to use the 2-in-1 as a touchscreen, I want to use the on-screen keyboard, and when I am using it like a normal laptop, I don't.

 How do I accomplish such goal?

Thanks,
Eli D.
