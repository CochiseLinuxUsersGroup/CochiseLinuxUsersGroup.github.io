LibreOffice

From Rex Bouwense · Jul 10, 2020

In the last several days there has been some discussion on
LibreOffice's pending release of version 7 and the use of the term
"personal edition". Most if not all of you are using LibreOffice and
this note is to relieve you of any anxiety of the release having any
less functionality. You can read a discussion here:
https://itsfoss.com/libreoffice-personal-edition-issue/ and the board's
response to the controversial response of some users as well as comments
in the foundation's blog here:
https://blog.documentfoundation.org/blog/2020/07/06/board-statement-on-the-libreoffice-7-0rc-personal-edition-label/
So have no concern (at least not yet). We will still have LibreOffice.
Rex Bouwense
