Hey, long time arch fanboy here...  I would recommend arch to a new user only if they are interested in how the system works with minimal bloat.  I picked up arch from a lug member who recommend I go GUI free for a month to learn the how to configure, break, reinstall, restore, and so on.

Arch is a blank slate (a pretty slick one).  Blank slates are great for learning.  One keeps arch around cause well...  pacman is pretty rad...  Assuming you like to tinker :)
