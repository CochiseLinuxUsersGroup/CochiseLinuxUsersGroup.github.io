Ubuntu 2020.04.1

From Rex Bouwense · Jul 20, 2020

For those of you that are using Ubuntu, the first point release
(20.04.1) of the newest version which was supposed to be released of
Thursday 23 July has been pushed back to 06 August. What does that mean
to those of you who are already using 20.04? Not much. If you have
already installed it, all that you have to do is continue to download
and install the published updates and when the point release comes out
your system will automatically become 20.04.1. For those of you that are
still using 18.04 and waiting to upgrade your system to 20.04 you will
not be given that option until the first point release comes out so you
will have to wait two more weeks (or you could do a fresh install). If
you opt to do the fresh install be sure any back up your data.
Rex
