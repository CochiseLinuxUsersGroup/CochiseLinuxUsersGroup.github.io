From Rex Bouwense · Jul 18, 2020

If you do a fresh install of Linux Mint 20.0 you will have to re-install WINE.  If you do an upgrade to the new version it should not affect anything that you have installed or your data.  However, you should notice that I said should.  An upgrade from one version to another has been known to brick a computer, or in other words cause it to be inoperable, so it would require a bit of work to get it going again (which is way above my pay grade.)  I have attempted 5 version upgrades and only been successful once.  Others have never had a problem and upgrade their computers all the time without problems.  If you do an upgrade back up your data because you may lose it during the upgrade.  It is not supposed to happen but remember Murphy's Law.  As for the second part of your question, I did a quick search and found this site:  https://www.youtube.com/watch?v=5OcIgDRew08.

Rex
