for those ready to jump in the deep end (arch linux) [another question from last meeting]

From Devi Garcia · Jun 17, 2018

https://antergos.com/ : this is basically arch with a GUI installer so you don't have to learn CLI to just install the OS.. i personally use this and have no issues.. has tons of options for customization when you install and gives you all the benefits of arch without the hassle.. 

https://manjaro.github.io/ :  this one is almost like antergos but from what i last read on the differences from arch and antergos is.. manjaro uses its own custom kernel so its not an 100% true "Arch" OS.. but a modified one.. and Manjaro has a community built version for just about any DE and is very popular.. 

these are both easy ways to jump into Arch without the 3hr CLI install that true arch would take..
