What's New with Ubuntu 22.10

From Rex Bouwense · Oct 23, 2022

Ubuntu 22.10 was released on 20 October 2022 after a late bug repair caused a delay of several hours. It is an interim release and as such is only supported for 9 months. Here are some of the changes that come with the new version.

1. The desktop environment has been fully updated to Gnome 43.

2. The spread effect (from Unity) has been re-introduced. It shows all open windows of the same application when you click its ICON in the Dock.

3. Unity is now an official Canonical “flavor”.

4. Ships with Linux kernel 5.19 (which is said to improve SNAP starting times on some devices)

5. PipeWire is now the default audio system replacing Pulse Audio.

6. There is a brand new quick settings menu.

7. Ships with;

    Firefox: 105.0.1

    Thunderbird: 102.3.0

    LibreOffice: 7.4.2.1

    Files (Nautilus): 43.0

    GCC: 12.2.0

    Open SSL: 3.0.5

Rex Bouwense
