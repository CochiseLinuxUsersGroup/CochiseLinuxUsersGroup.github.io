[link] It’s Now Easier to Install Acer Firmware on Linux

From Devi Garcia · Sep 11, 2019

Big news for Linux users sporting Acer hardware: the company has officially joined the LVFS!

“The what-vs?”

Y’know, the Linux Vendor Firmware Service! That awesome initiative spearheaded by open source developer Richard Hughes that lets well-known hardware companies — Dell! Lenovo! Wacom! Etc! — safely distribute firmware updates to Linux users, sans hassle.
