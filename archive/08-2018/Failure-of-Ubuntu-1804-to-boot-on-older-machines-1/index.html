At our most recent installfest we installed 18.04 on a Mac-Mini and the screen froze just prior to login.  I attempted to replicate the problem at home on an old Dell Opti-Plex and it too failed to boot but it would install and boot to any of the other Ubuntu "flavors" even Kubuntu which is just as robust as Ubuntu.  Many things were tried, including nomodeset.  While attempting to take nomodeset off the grub menu I discovered that Ubuntu 18.04 now comes with gdm3 as the default login display manager which is a lot heavier that the older LightDM that used to be the default login display manager.
