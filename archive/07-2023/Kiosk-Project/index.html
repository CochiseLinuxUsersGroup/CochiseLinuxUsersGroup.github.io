From David Paige · Jul 30, 2023

I also saw the porteus-kiosk package. It looks a great solution, since
the image on the hard drive is an iso, which prevents miscreants from
modifying the base image (or at least makes it much more difficult.)

It's probably better to start with an image designed for this purpose,
than to try and figure out what can be removed from a standard Ubuntu to
get to the same point.
