then run

sudo tar -xvjf ./waterfox.tar.bz2

then simply open the new folder created(mine was called waterfox) and run ./waterfox to launch it.

TL;DR

sudo mv ~/Downloads/waterfox.tar.bz2 /opt
cd /opt
sudo tar -xvjf ./waterfox.tar.bz2
cd ./waterfox
./waterfox
