Linux Classes

From Rex Bouwense · Dec 11, 2022

The Cochise Linux User Group will conduct classes at the Warrior
Healing Center on Linux and Ubuntu starting on 09 January according to
the following schedule.

09 January, 1700-1800 in the main conference room. Subject:
Introduction to Linux

16 January, 1700-1800 in the main conference room. Subject: Security
Considerations

23 January, 1700-1800 in the computer lab. Subject: Configuring Your
Desktop

30 January, 1700-1800 in the computer lab. Subject: Using Firefox (web
browser)

06 February, 1700-1800 in the computer lab. Subject: Using Thunderbird
(a mail client)

Since some of the classes will be conducted in the computer lab and
will be hands on, seating is limited. There are only 7 seats available
so it will be first come first served. Please register by sending an
email to Rex Bouwense, majb@azloco.com or by contacting him directly.
Other classes may be scheduled depending upon the needs of the attendees.

Rex Bouwense
