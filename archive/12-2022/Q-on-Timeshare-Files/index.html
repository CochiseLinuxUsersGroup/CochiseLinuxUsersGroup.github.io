Re: Q on Timeshare Files

From Devi Garcia · Dec 17, 2022

If you instead want to move your existing backup folder to a new location. Then do as the followings:

  1. Locate the "timeshift" folder you want to move. You can check where using the GUI but usually, it's the root folder (/timeshift).
  2. Move the "timeshift" folder to the desired storage device (HDD, SSD, etc...) root location (/). You can do it the command line way or launch a file explorer with the sudo rights.
  3. Change the Location settings in the Timeshift GUI to the new backup's location.
  4. Profit.
So you’d just want to find that “/timeshift” folder on your computer and copy it’s contents or change it to an external.
